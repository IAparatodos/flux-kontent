# 🎬 Agenda de Videos - Instrucciones Fáciles

## ⚡ Inicio Rápido (1 comando)

### En Mac/Linux:
```bash
./iniciar.sh
```

### En Windows:
```bash
iniciar.bat
```

O si no funciona, doble clic en el archivo `iniciar.bat`

## 🌐 Acceder a la Agenda

Después de ejecutar el script:

- **Desde tu ordenador:** http://localhost:8000
- **Desde tu móvil:** http://TU_IP:8000 (la IP se muestra al iniciar)

## 📋 Requisitos

Solo necesitas **Python 3.8 o superior** instalado.

Verificar si tienes Python:
```bash
python --version
```

Si no tienes Python, descárgalo de: https://www.python.org/downloads/

## 🛑 Detener el Servidor

Presiona `Ctrl + C` en la terminal

## 🚀 Opción 2: Usar en la Nube (Sin instalar nada)

Si prefieres no instalar nada y acceder desde cualquier lugar, puedo desplegarlo en:
- **Render** (gratis, siempre disponible)
- **Railway** (gratis, muy rápido)
- **Heroku** (gratis)

Solo tienes que pedírmelo y lo configuro para ti.

## ❓ Problemas Comunes

### "uvicorn no encontrado"
```bash
pip install uvicorn fastapi
```

### "No puedo acceder desde el móvil"
1. Asegúrate de que el móvil y el ordenador están en la misma WiFi
2. Desactiva el firewall temporalmente
3. Usa la IP que muestra el script al iniciar
